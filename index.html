Same frames. Same bytes.

Wezen turns Ruby pixel data into deterministic APNG, GIF, PNG, and asciinema media. No runtime dependencies beyond the standard library.

Install the gem Read the guide

Encode for the place it plays.

One animation timeline produces stable assets for browsers, terminals, documentation, and test fixtures.

APNG

Preserves full RGBA pixels and writes changed frame rectangles when it can do so exactly.

GIF89a

Builds deterministic global or adaptive palettes with optional Floyd–Steinberg or Bayer dithering.

PNG

Writes compact, predictable still images with Ruby’s standard zlib implementation.

Cast v2

Serializes terminal output, input, and resize events in asciinema JSON Lines format.

Shape the timeline before export.

Pixel operations stay explicit. Repeated frames coalesce, delays remain visible, and every encoder receives the same source.
